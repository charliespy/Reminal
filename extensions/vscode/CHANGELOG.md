# Changelog

## 0.2.1

- The cloud button's list shows the other reminals running on this machine,
  and opens one in a terminal here. Closing that terminal leaves the session
  running.
- A reminal terminal's tab takes the session's name, and follows it when the
  session is renamed.

## 0.2.0

- reminal Copy and reminal Paste in the Explorer's right-click menu: copy a
  file or folder, and paste it on another machine with a one-time code.
- The cloud button's list shows the ports you share with reminal, with Copy
  link, Open in browser and Stop sharing, and Share a Port to share another.
- Choosing reminal from the + menu no longer shows another terminal for a
  moment before the new one.

## 0.1.1

- A clearer store listing, and a few words on what else reminal can do.

## 0.1.0

- A reminal terminal profile, a cloud button in the terminal panel that
  lists your reminal terminals, and Open reminal in This Folder on a
  terminal tab's right-click menu.
- Working, Needs you and Done beside each reminal terminal's tab, with a
  notification when one starts waiting for you, and an optional summary in
  the status bar.
- A notification with the session's PIN, Copy link and Open in browser.
- Share for a Person and Share for an AI Agent, with the same messages as
  the web page's Share buttons.
- When reminal isn't installed, an Install reminal button that runs the
  install command in a terminal.

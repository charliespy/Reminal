# 3.17.15

Added
- A session now tells you when its agent has hit its usage limit, and when the limit resets. `reminal list` shows "limited until 15:00", so you know it is waiting, not working or done.
- This works for Claude Code, Codex, Gemini CLI, Qwen Code, OpenCode, goose, Crush and Cursor's agent.
- With Claude Code 2.1.78 or newer, run `reminal integrate` again and the limit shows the moment Claude Code turns a message away.
- More agents are recognized when they need you to sign in: goose, Crush, OpenCode, Cursor's agent and Qwen Code.

Fixed
- A session whose machine went down before you sent its agent anything now comes back with that agent started fresh, instead of a bare shell where your next line ran as a command.
- A session that started less than a minute before its machine or container restarted now comes back, instead of being taken as still running and lost.
- Typing "continue" to an agent that is still at its limit no longer makes the session look busy.

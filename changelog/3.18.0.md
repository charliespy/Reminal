# 3.18.0

Added
- Put a session to sleep to free its memory: `reminal sleep <name>`, or the moon button on a session in Machines. Open it again, or run `reminal wake <name>`, and it comes back as itself: the same link, PIN, scrollback and conversation.
- Sleep works with Claude Code, Qwen Code, OpenCode and pi. Other agents stay awake and say why.
- A sleep never quietly loses work. If something would end, such as a job still running, a reply in progress, a question waiting for you, or text you typed but didn't send, it tells you what and asks first.
- A sleeping session stays asleep through a restart. Anything you type while it wakes waits until its agent is back, and you can send it or drop it if the agent doesn't come back.

Improved
- After a restart, OpenCode and pi come back on their exact conversation, even with several in one folder. Run `reminal integrate` again to set this up.

# 3.17.14

Fixed
- A session whose machine went down seconds after you started Claude Code or another agent in it now comes back with that agent, on the same conversation, not as a bare shell.
- While your machine can't reach reminal, your terminal says so once and once more when it is back, instead of a new line every 30 seconds pushing your work off the screen.
- Running `reminal integrate` again after Claude Code has rewritten its settings no longer adds a second copy of a reminal hook.

Improved
- Agents using reminal can press Ctrl-C, Esc, Tab, the arrow keys and other keys in a session, so they can stop a command that hangs.
- Codex gives reminal's tools three minutes before giving up on them, so longer actions finish.

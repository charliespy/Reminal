# 3.17.43

Improved
- Sessions in Codex, Gemini CLI, Qwen Code, OpenCode, goose, Amp, pi and Antigravity now show as
  limited when they run out of usage, using each tool's current wording.
- Claude Code's newer limit messages, such as extra usage running out or a limit that continues
  automatically later, now show the session as limited.

Fixed
- A session no longer shows as limited or logged out when the agent only quotes or mentions such a
  message in its answer.
- An agent that is working no longer shows as logged out because of a sign-in line that is only a
  hint, or a login another server asks for.
- Sessions whose agent's login expired or whose key was refused now show as logged out, in more tools.

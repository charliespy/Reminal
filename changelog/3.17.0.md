# 3.17.0

Added
- `reminal copy` copies a whole folder too. It arrives on the other machine as it was when you copied it, permissions included, so private files stay private. A pasted name that starts with a dot, such as `.ssh`, is saved as `pasted-.ssh`, so it never lands as a hidden file or folder. A pasted folder is never a working Git repository, and you're told what was renamed to keep it that way.
- The VS Code extension can now copy and paste files and folders from the Explorer, and list, share and stop the ports you share.

Fixed
- `reminal stop <id> --yes` stops that exact session or port forward, or nothing, so a script can't stop a different one by a similar name.
- When `reminal expose` can't reach the relay, it now says why right away, for example a system missing its CA certificates, instead of a timeout, and it no longer keeps retrying in the background.
- A terminal you stop sharing with Ctrl-] no longer sometimes stays in `reminal list` as if it were still shared.
- Pasting a used code through a relay you run yourself on Windows now says the code is too old or invalid, instead of a connection error.

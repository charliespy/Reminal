# 3.17.12

Improved
- Claude Code, Cursor, Codex, pi and OpenCode turning away the login or key you gave them now show as logged out, so you know to sign in again.
- OpenCode still starting up shows as at work, not done.
- Keys waiting while a session connects show how many characters are held, and a paste too big to hold tells you it was not sent.
- A busy machine tells each waiting device when to try again, in turn, instead of all at once.
- An install kept up to date by something else, like an image or a package manager, says so and leaves updates to it.
- Networking libraries and the Go toolchain are updated to their latest versions.

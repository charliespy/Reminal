# 3.16.8

Fixed
- With closed-lid mode on, opening the lid after it has been shut for a while now brings your screen back to the brightness it had, instead of leaving it dim.

Improved

- The window helper on Mac now starts with only the settings it needs, the same way the screen helper does.

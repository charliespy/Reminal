# 3.16.7

Fixed
- A coding agent started with its own system prompt now comes back to the same conversation after your computer restarts, with that prompt kept. Before, it could start a new conversation instead.
- Restoring sessions after a restart is safer: nothing in an agent's saved settings can run a command of its own while the agent is brought back.
- With closed-lid mode on, your screen's brightness always comes back when you open the lid, even if reminal was stopped while it was shut.

Improved
- reminal's screen and window helpers now start with only the settings they need, so other programs on your computer can't change how they behave.

# 3.16.11

Improved
- When the page drops a dead connection, it is back in under a second instead of up to ten.
- After you switch sessions, the terminal fills your screen straight away instead of drawing small for a few seconds.
- A Claude Code session that finished its turn with shells still running in the background now shows them reliably, even when they are off its screen.
- After a restart, a restored session can be reached at once, and its coding agent picks up behind it. A conversation too big for a small machine's memory is not resumed: the session tells you, with the command to run yourself.
- A restored session no longer keeps you waiting while its history loads: you can reach it first, and the history fills in.
- The page opens faster when you come back to it.

Fixed
- Typing fast no longer loses a repeated key: `44` stays `44`, and `$((` stays `$((`.
- On a first visit, the tour no longer takes your keys: what you type goes to the session, Enter included.
- A session you switch back to reconnects at once if its connection drops soon after.
- The page no longer garbles a full-screen program's screen after a reconnect.
- Controlling a machine no longer says it is "too old" when someone else has it open at the same time.
- Removing a device now always signs it out of a session, even one that started in that same second.

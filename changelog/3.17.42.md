# 3.17.42

Improved
- After a restart, a session's agent comes back as soon as its shell is ready, instead of
  after about 10 seconds. What you type while it comes back is kept and arrives after it.
- Posting a moment asks before throwing away what you typed when you tap outside it.
- The copy and select menu stays on screen when a selection starts at the left edge.

Fixed
- On Windows, keys typed while a session was coming back after a restart could be lost.
- Stopping one session now ends it right away. Before, it could keep running.
- Moments no longer name the coding agent a session runs.
- Sessions whose connection dropped without notice are now cleaned up on the relay.

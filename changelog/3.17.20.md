# 3.17.20

Fixed
- The number of running shells shown for a session is no longer thrown off by lines in its output.
- When a session can't be reached, the message now shows over the terminal instead of being typed into it.
- After a session comes back from a restart, its new prompt starts on a line of its own, and the "restored" note no longer leaves stray text beside it.
- On a phone, tapping a session in the switcher while it is still connecting no longer interrupts the connection.
